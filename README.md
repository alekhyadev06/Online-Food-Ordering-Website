# 🍔 Food Ordering Website

A responsive Food Ordering Website developed using React.js and Bootstrap.  
This project displays food items with images, prices, and Add To Cart buttons using reusable React components.

---

## 🚀 Features

- Responsive Navbar
- Food Cards with Images
- Display Food Prices
- Add To Cart Buttons
- Modern UI Design
- React Component Structure
- Bootstrap Styling

---

## 🛠 Technologies Used

- React.js
- JavaScript
- Bootstrap
- HTML
- CSS
